# English Speaking Practice for Software Developers

A comprehensive 6-month plan to improve English speaking skills, specifically designed for software developers.

## 📚 What's Included

- **英语口语提升计划.md** - Complete 6-month learning roadmap (3 phases)
- **软件开发常用英语.md** - Essential phrases for software development scenarios (Daily Standup, Code Review, etc.)
- **学习记录.md** - Daily practice tracking templates
- **第一周快速开始.md** - Week 1 quick start guide

## 🎯 Goals (6 months)

- Conduct daily conversations in English
- Participate in technical discussions and meetings
- Clearly express technical viewpoints
- Handle basic work and life scenarios

## 🚀 Quick Start

1. Open `第一周快速开始.md` (Week 1 Quick Start Guide)
2. Complete Day 1 environment setup (30 minutes)
3. Follow the daily practice schedule
4. Track your progress in `学习记录.md`

## 💡 Core Principles

- **Consistency > Intensity**: 30 minutes daily beats one 3-hour session weekly
- **Fluency > Grammar**: Speak first, perfect later
- **Output > Input**: Practice speaking, not just listening
- **Create Environment**: Change phone/IDE to English, use AI for practice

## 📅 Learning Phases

### Phase 1 (Month 1-2): Pronunciation & Daily Expressions
- Pronunciation drills (th, r, v/w, l)
- Shadowing practice
- Self-talk exercises

### Phase 2 (Month 3-4): Technical English & Fluency
- Technical content practice
- Tech topic presentations
- Real conversation practice

### Phase 3 (Month 5-6): Real-world Application
- Scenario simulations (interviews, meetings)
- Live conversations with native speakers
- Project presentations in English

## 🛠️ Recommended Resources

- **Pronunciation**: ELSA Speak, Rachel's English
- **Technical Content**: Fireship, freeCodeCamp, Traversy Media
- **Practice**: ChatGPT (voice mode), HelloTalk, Tandem
- **Tutors**: italki, Preply

## 📈 Progress Checkpoints

**Month 2**:
- Fluent 2-minute self-introduction
- Basic daily conversations
- Clear pronunciation

**Month 4**:
- 5-minute technical explanations
- Participate in tech discussions (70%+ comprehension)
- 15-minute continuous conversations

**Month 6**:
- Attend English technical meetings
- Technical interviews in English
- Handle work communication in English
